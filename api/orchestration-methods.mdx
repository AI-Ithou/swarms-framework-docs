## Overview

`swarms.structs.multi_agent_debates` provides structured conversation orchestrators for coordinating multiple agents in turn-based discussions. Each orchestrator takes a list of `Agent` instances, drives them through a scripted exchange, and returns the resulting conversation history.

Both classes live in `swarms.structs.multi_agent_debates` and are imported from that module directly — they are not re-exported from the top-level `swarms` package. A function form of the two-agent debate, `one_on_one_debate`, lives in `swarms.structs.deep_discussion`.

## Installation

```bash
pip install -U swarms
```

## Available Methods

| Method | Description | Use Case |
|---|---|---|
| `OneOnOneDebate` | Turn-based debate between exactly two agents | Philosophical discussions, adversarial arguments |
| `one_on_one_debate` | Function form of the two-agent debate, without the introductions | Quick two-agent exchanges |
| `ExpertPanelDiscussion` | Expert panel with a moderator guiding rounds | Professional discussions, expert opinions |

<Note>
  None of these orchestrators records the task itself, so the first recorded message is the first agent's reply. The default `output_type="str-all-except-first"` leaves that reply out and joins the rest without speaker names. Pass `output_type="str"` for a labelled transcript of every turn, or `"list"` to iterate messages.
</Note>

## OneOnOneDebate

Simulates a turn-based debate between two agents for a specified number of loops. Both agents are first given a short introduction naming their opponent, then they alternate: each agent's response becomes the next agent's prompt. A run makes `2 + max_loops` agent calls.

Each turn records, and passes on, whatever the speaker's `run()` returns. With the `Agent` default `output_type`, that is the agent's conversation rather than just its reply, so it grows every turn. Give both agents `output_type="final"` to exchange only replies, or use the `one_on_one_debate` function below, which does this for you.

### Attributes

<ParamField path="max_loops" type="int" default="1">
  Number of conversational turns. One agent speaks per loop, alternating.
</ParamField>

<ParamField path="agents" type="list[Agent]" default="None">
  Exactly two agents. `run()` raises `ValueError` if the list does not contain exactly two entries.
</ParamField>

<ParamField path="img" type="str" default="None">
  Optional image passed to each agent's `run()` call.
</ParamField>

<ParamField path="output_type" type="str" default="str-all-except-first">
  Format for the returned conversation history.
</ParamField>

### run()

Executes the debate between the two agents.

```python
def run(self, task: str)
```

<ParamField path="task" type="str" required>
  The debate topic used as the opening prompt.
</ParamField>

<ResponseField name="return" type="str | list | dict">
  The conversation history, formatted according to `output_type`.
</ResponseField>

<Warning>
  `agents` must contain exactly two agents. Any other number raises `ValueError` when `run()` is called.
</Warning>

### Example

```python
from swarms import Agent
from swarms.structs.multi_agent_debates import OneOnOneDebate

agent1 = Agent(agent_name="Philosopher1", model_name="gpt-5.4", output_type="final")
agent2 = Agent(agent_name="Philosopher2", model_name="gpt-5.4", output_type="final")

debate = OneOnOneDebate(
    max_loops=3,
    agents=[agent1, agent2],
    output_type="str",
)

result = debate.run("Is artificial intelligence consciousness possible?")
print(result)
```

## one_on_one_debate

The function form of the two-agent debate. It skips the introductions, and on each turn it records the speaker's final answer and passes only that answer to the other agent, so the context does not grow with each agent's transcript.

```python
def one_on_one_debate(
    max_loops: int = 1,
    task: str = None,
    agents: list[Union[Agent, Callable]] = None,
    img: str = None,
    output_type: str = "str-all-except-first",
) -> list
```

<ParamField path="max_loops" type="int" default="1">
  Number of turns. One agent speaks per turn, alternating, starting with `agents[0]`.
</ParamField>

<ParamField path="task" type="str" required>
  The opening message sent to the first agent.
</ParamField>

<ParamField path="agents" type="list[Agent]" required>
  Exactly two agents. Any other number raises `ValueError`.
</ParamField>

<ParamField path="img" type="str" default="None">
  Optional image passed to each agent's `run()` call.
</ParamField>

<ParamField path="output_type" type="str" default="str-all-except-first">
  Format for the returned conversation history.
</ParamField>

```python
from swarms import Agent
from swarms.structs.deep_discussion import one_on_one_debate

optimist = Agent(agent_name="Optimist", model_name="gpt-5.4")
skeptic = Agent(agent_name="Skeptic", model_name="gpt-5.4")

transcript = one_on_one_debate(
    max_loops=4,
    task="Will open-weight models match frontier models within two years?",
    agents=[optimist, skeptic],
    output_type="str",
)
print(transcript)
```

## ExpertPanelDiscussion

Simulates an expert panel discussion with a moderator guiding the conversation. Before the first round, the moderator and each expert are briefed on the panel's participants. Each round, the moderator introduces the topic, every expert responds in turn to the moderator's message, and the moderator then synthesises the responses into a follow-up question that becomes the next round's topic.

The moderator receives the round's expert replies as a labelled transcript, one `Expert_Name: reply` block per expert. A run makes `1 + N + max_rounds * (N + 2)` agent calls for `N` experts.

Like `OneOnOneDebate`, the panel records whatever each agent's `run()` returns. Give the moderator and experts `output_type="final"` so only their replies are recorded and passed on.

### Attributes

<ParamField path="max_rounds" type="int" default="3">
  Number of discussion rounds. Note this is `max_rounds`, not `max_loops`.
</ParamField>

<ParamField path="agents" type="List[Agent]" default="None">
  Expert panel participants. At least two are required.
</ParamField>

<ParamField path="moderator" type="Agent" default="None">
  The moderator agent who introduces each round and synthesises responses.
</ParamField>

<ParamField path="output_type" type="str" default="str-all-except-first">
  Format for the returned conversation history.
</ParamField>

### run()

Executes the panel discussion.

```python
def run(self, task: str)
```

<ParamField path="task" type="str" required>
  The main topic for discussion, used as the first round's topic.
</ParamField>

<ResponseField name="return" type="str | list | dict">
  The conversation history, formatted according to `output_type`.
</ResponseField>

<Warning>
  `run()` raises `ValueError` if fewer than two experts are supplied in `agents`, or if `moderator` is not set.
</Warning>

### Example

Full example: [Healthcare Panel Discussion](https://github.com/kyegomez/swarms/blob/master/examples/multi_agent/orchestration_examples/healthcare_panel_discussion.py)

```python
from swarms import Agent
from swarms.structs.multi_agent_debates import ExpertPanelDiscussion

moderator = Agent(agent_name="Moderator", model_name="gpt-5.4", output_type="final")
expert1 = Agent(agent_name="AI_Expert", model_name="gpt-5.4", output_type="final")
expert2 = Agent(agent_name="Ethics_Expert", model_name="claude-sonnet-4-6", output_type="final")
expert3 = Agent(agent_name="Neuroscience_Expert", model_name="gpt-5.4", output_type="final")

panel = ExpertPanelDiscussion(
    max_rounds=2,
    agents=[expert1, expert2, expert3],
    moderator=moderator,
    output_type="str",
)

result = panel.run("What are the ethical implications of AGI development?")
print(result)
```

## Other Conversation Patterns

Eight further scripted conversation patterns — interview series, peer review, mediation, brainstorming, trial simulation, council meeting, mentorship, and negotiation — ship as standalone example scripts rather than as part of the library. They are built entirely from the public `Agent` and `Conversation` APIs, so they are meant to be copied into your project and adapted, not imported from `swarms`.

Browse them at [`examples/multi_agent/alternate_debates/`](https://github.com/kyegomez/swarms/tree/master/examples/multi_agent/alternate_debates) on GitHub — each file contains one pattern plus a runnable demo.
